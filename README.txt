نسخة دقيقة مهارة القابلة للتثبيت كتطبيق
ارفعي الملفات الخمسة إلى جذر مستودع daqeeqat-mahara-teacher في GitHub (لا ترفعي ZIP نفسه).
استبدلي index.html القديم، وأضيفي manifest.webmanifest و sw.js و icon-192.png و icon-512.png.
بعد اكتمال النشر افتحي الرابط في Chrome ثم القائمة ← تثبيت التطبيق.
إذا استمر ظهور مثبت مسبقًا، تحققي من اختصارات Chrome والتطبيقات السابقة، وتجنبي حذف البيانات إذا كانت هناك نتائج محفوظة.
